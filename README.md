## FAQ

### Is OmniPatch safe to use?

Yes, OmniPatch is safe. The executable is regularly scanned for tool and does not contain any malicious code. It only modifies specific license or feature-check files within the target applications.

OmniPatch supports ChatGPT, Claude, Perplexity AI, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant. Support for additional AI tools may be added in future updates.

### How often is OmniPatch updated?

We aim to release updates within 1-2 weeks after a new version of any supported AI application is released to ensure continued compatibility and feature unlocking.

### Will using OmniPatch affect my AI account's safety?

OmniPatch modifies the local application files on your device and does not interact with your AI provider's account or servers. Your account credentials remain safe and untouched.

### Do I need to disable my anticomponent software?

Some anticomponent tools may flag the patcher as a potential threat due to its file-modifying nature (false positive). You may need to add an exception, but it is not inherently malicious.

### Can I receive updates for OmniPatch?

Yes. OmniPatch includes an auto-updater that checks for new versions on launch. You can also manually download the latest version from the GitHub repository.

### What should I do if a patch fails to apply?

Ensure you are running the patcher as administrator and that the target AI application is completely closed. If the issue persists, check the GitHub Issues page for troubleshooting or report the problem.
